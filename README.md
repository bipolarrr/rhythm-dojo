# Rhythm Dojo

**소개** · [실행·조작](Docs/getting-started.md) · [개발 안내](Docs/development.md)

Rhythm Dojo는 도장을 배경으로 하는 **4레인 키보드 리듬 게임**입니다. 음악에 맞춰 D · F · J · K 키로 노트를 치고, 롱노트는 길게 눌러 콤보와 점수를 쌓습니다.

게임 안에서 직접 채보를 만들 수도 있습니다. 음원을 불러와 파형을 보며 노트를 배치하고, 바로 테스트 플레이를 한 뒤 돌아와 고칠 수 있습니다.

현재 Unity로 개발 중이며, 기본 수록곡은 테스트·데모 곡 위주입니다. 플레이와 채보 편집의 기본 기능을 갖추고 화면과 사용성을 다듬고 있습니다.

직접 실행하려면 **Unity 6000.3.23f1**이 필요합니다. 설치 후 실행 방법과 조작법은 [실행 안내](Docs/getting-started.md)를 참고하세요.
