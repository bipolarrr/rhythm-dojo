# 수련 레인과 타격 피드백 검증

2026-11-18 · `emergency` · Unity 6000.3.23f1

Gameplay 씬의 중앙 레인을 먹청색 옻칠 목재와 황동 테두리로 구성했다. 각 레인의 목제 받침 윗면이 연속된 금색 판정선에 닿는다. 상아색 단타는 수평 타격면으로, 롱노트는 옥색 머리와 직조 띠, 좁은 끝마디로 읽힌다. 같은 모드로 다시 초기화할 때는 씬에 저장된 레인과 받침을 재사용한다. 에디터의 채보 미리보기도 같은 노트 프리팹을 사용한다. [네 페이즈의 실제 플레이 화면](../Docs/verification-images/strike-interface-phases.jpg)

타격 순간에는 짧은 섬광이 접점에 맺히고, 주색과 금빛의 붓획이 레인 아래쪽으로 펼쳐진다. 굵은 충격이 먼저 사라지고 가는 잔상이 뒤따른다. 같은 레인의 다음 판정은 직전 잔상을 교체한다. 롱노트에는 접촉 표시가 남고 미스에는 낮게 떨어지는 붉은 두 획을 사용한다. 연격 숫자는 레인 입구 위에서 움직이며 50연격부터 10연격 단위로 박동이 조금 커진다. [롱노트 유지 중 동시치기와 64연격](../Docs/verification-images/strike-chord.jpg)

| 내부 등급 | 한글 표시 | 시각적 반응 |
| --- | --- | --- |
| Perfect | 절묘 | 옅은 금색 글씨와 크게 퍼지는 충격 |
| Good | 명중 | 밝은 청록색 글씨와 짧은 충격 |
| Miss | 빗나감 | 주색 글씨, 아래로 가라앉는 획, 연격 해제 |

판정창·점수·채보 시계는 기존 값을 사용한다. 독도체의 기존 OFL 라이선스를 확인했다. 새 PNG 여섯 개의 적용 위치와 내장 ImageGen에 사용한 원문 프롬프트를 기록했다. [폰트 라이선스](../Assets/Game/Fonts/Dokdo-OFL.txt) · [아트 제작 기록](../Docs/strike-interface-art.json)

## 검증 결과

변경과 관련해 실행한 고유 테스트 50개가 각각의 최종 실행에서 통과했다. EditMode 15개와 PlayMode 35개이며 최종 결과에 실패·건너뜀·불확정은 없다. 전체 프로젝트 스위트는 실행하지 않았다.

| 확인한 상황 | 관찰·검사 내용 |
| --- | --- |
| 저밀도와 네 배경 | 실제 Gameplay 씬에서 도장 문 개방, 밝은 정상, 고속 질주, 목인 파괴 및 미파괴 종료를 캡처했다. 배경 카메라가 움직이는 동안 레인 투영과 스크롤 배율을 확인했다. |
| 폭타·트릴·계단·잭 | 초당 16개 시점의 입력을 실제 판정기와 노트 프리팹에 공급했다. 이어지는 롱노트 중 세 레인 동시치기, 50을 넘긴 콤보와 연속 미스 후 콤보 소거를 확인했다. |
| 타격과 판정 피드백 | 성공·실패별 메시가 판정선 아래와 해당 레인 폭 안에 머물렀다. 같은 레인의 반복 입력, 동시 입력, 유지·해제, 일시정지·초기화, 타격음 출력을 확인했다. |
| 화면과 조작 | 상·중·하 판정 위치, 설정 보정 화면의 한글 판정, 서체, 조립된 프리팹, 마디선, 투명도 변경 시의 나뭇결, 채보 에디터 미리보기, 메뉴에서 실제 플레이 진입을 확인했다. |
| 곡 종료 | 실제 음악 시계로 Results에 도달했다. 곡 종료 대기 중 재시작이 예약된 전환을 취소하는 경우도 통과했다. |

처음에는 붓자국 메시의 일부가 판정선과 레인 경계를 넘었다. 획의 시작 높이와 폭을 수정한 뒤 모든 등급의 경계 검사를 재실행했다. 예전 캡처와 오디오 검사가 임의의 뷰포트와 단일 입력 음원을 전제하던 부분은 HUD가 사용하는 레인 카메라와 실제 음성 풀을 관찰하도록 바꿨다.

영상은 Unity Game View에서 검증 채보를 1/32초 간격으로 진행하며 얻은 190프레임이다. 원본 화면은 1920×1080이며 공유용 영상은 1280×720, 32fps, 무음이다. 실제 음악 시계와 오디오 출력은 별도 PlayMode 사례로 확인했다. [검증 채보 영상](../Docs/verification-images/strike-patterns.mp4)

## 미검증 항목

Windows 독립 플레이어 빌드, 장치별 프레임 시간과 입력 지연 실측, 숙련 플레이어의 수동 난독성 평가는 수행하지 않았다.
