Source baseline: 9e2694b. The test-only SongClockResumeTests run failed 2/2 (task3-red.json): Resume immediately exposed Running=true, and a stale source cursor differed by 72,693 samples from the logical-song-time-derived position.

SongClock now stops and seeks from (pausedSongTime - chartOffset), rounds to a sample, and schedules at a future DSP anchor. Initial audio lead is preserved separately; sampleCount is an end sentinel so finished audio is never clamped back onto its final sample. User input calibration is excluded. ScheduledStartDspTime retains the origin mapping, while ResumeDspTime exposes the resume anchor for diagnostics. Activation resets interpolation to the observed DSP value so the first logical time cannot precede its frozen value.

IScheduledResumeClock adds a Unity-free deferred completion/cancellation contract. Coordinator keeps IsPaused and deferred releases until the anchor; input dispatch can complete a due resume before Tick, and pre-anchor timestamps use the original pause calibration even if delivered after Tick. A repeated Pause cancels pending scheduling, including the clock-completed-before-coordinator ordering. Reset cancels the source reservation. The pause menu keeps its countdown during the lead, cancels on Escape/focus loss, and reopens when a reset invalidates the reservation.
