- Unity 재시작 후 CLI 연결이 복구됐다. 사용자가 직접 Unity를 종료했고, 자동화된 저장 없는 종료는 승인 검토에서 차단되어 실행하지 않았다.

## 1.1 이전 커서 클릭 및 미리듣기

- 음수 구간 클릭 시 보기 위치만 유지하던 동작을 확장했다. 커서 시각도 -10.1에 해당하는 최소 시각부터 음원 끝까지 선택할 수 있다. 음수 시간은 시계에 음수 부호를 표시한다.
- AudioSource의 샘플 위치는 0 이상으로 제한하되, 미리듣기 커서는 음수 시각부터 진행한다. 음원은 해당 커서가 0초에 도달하는 DSP 시각에 예약 재생한다. 반속 재생도 대기 시간을 재생 속도로 환산한다.
- 음수 구간에서 일시정지·재개, 속도 변경, 정지 후 0초 복귀를 지원한다. 재생 따라가기의 보기 하한도 음수 그리드 하한을 사용한다.
- 실제 Saiki 128 BPM 회귀 테스트를 확장해 음수 클릭 시 커서·그리드 재생선 이동, 최소 위치 제한, 음수 위치 재생 중 음원 샘플 0 유지, 일시정지, 반속 재개 후 0초 통과와 음원 샘플 진행, 0.75초 탐색을 확인했다.
