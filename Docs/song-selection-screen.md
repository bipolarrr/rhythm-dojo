# 곡 선택 화면

Assets/Game/Scenes/Bootstrap.unity에서 실행하면 곡 선택 화면으로 이동합니다. 화면 원본은 SongSelectionLayoutBuilder이며 Game Tools > Scenes > Build Song Selection으로 재생성할 수 있습니다.

- 왼쪽은 제목, 작곡가/BPM, 앨범 표지, 난이도, 최고 기록, 옵션을 표시합니다. 표지는 비율을 유지하면서 구획 전체를 채웁니다.
- 화면은 청록색에서 올리브색으로 이어지는 배경, 상단 헤더, 하단 조작 바를 사용합니다. 선택한 곡은 파란색에서 보라색으로 이어지는 행으로 강조합니다.
- 오른쪽 목록은 작은 재킷, 곡명/작곡가, BPM, 난이도, 즐겨찾기 버튼을 표시합니다. 목록은 클릭하거나 방향키로 선택합니다. 선택 행에서 Enter 또는 플레이 버튼을 누르면 게임에 진입합니다. 게임 화면에서는 Space로 시작합니다.
- 전체/즐겨찾기 탭과 제목/작곡가/BPM 정렬을 지원합니다. 별 버튼으로 즐겨찾기를 저장합니다.
- 설정 버튼은 기존 오디오 설정 화면을 엽니다. Esc/뒤로 버튼의 확인 팝업에서 타이틀로 돌아갈 수 있습니다.
- 난이도는 기존 판정 허용폭을 변경하며, 곡의 채보 자체를 바꾸지는 않습니다. 속도는 입력 타이밍 보정과 같은 슬라이더로 1.0~10.0x 범위에서 0.1x씩 조절합니다. 고정속도/BPM 연동 선택 옵션은 표시하지 않으며, 플레이에는 설정한 속도를 적용합니다.
- 입력 타이밍 보정은 -200~+200ms입니다. 양수는 입력 시각에서 보정값을 빼므로 늦게 전달되는 입력에 사용합니다. 음원과 채보의 원래 오프셋은 그대로 유지합니다.
- 옵션, 즐겨찾기, 완주 기록은 로컬 PlayerPrefs의 RhythmDojo.Selection.v1에 저장됩니다. 곡 변경으로 옵션을 초기화하지 않습니다.
- 기록은 곡 ID/난이도별 최고 스코어와 해당 플레이의 최대 콤보입니다. 레이트는 (Perfect + Good × 0.5) / 노트 수 × 100, 스코어는 최대 1,000,000점입니다. S/A/B/C 기준은 95/90/80/70%입니다. 중도 종료와 에디터 테스트 플레이는 기록에 포함하지 않습니다.

## 임시 곡

Game Tools > Content > Add Demo Melody는 30초, 120 BPM, 4레인, 54노트의 멜로디 곡과 표지를 추가합니다. 기존 곡과 수정된 데모 에셋은 덮어쓰지 않고, 카탈로그에 중복 등록하지 않습니다. 일반 씬 재생성은 음원이나 채보를 생성하지 않습니다.

데모는 처음 실행할 때 기본 선택됩니다. 앨범 표지가 없는 곡에는 기본 표지를 사용합니다. 실제 곡을 추가할 때 SongDefinition의 Cover 필드에 Sprite를 지정하면 됩니다.
## 정렬 확인용 곡 정보

| 곡 | 작곡가 | BPM |
| --- | --- | --- |
| Foundation Pulse | Mira | 100 |
| Demo Melody | Yuna | 120 |
| Tempo Shift | Aster | 150 → 180 (6초 이후) |

BPM 정렬은 최저 BPM 기준입니다. BPM순은 Foundation Pulse → Demo Melody → Tempo Shift, 작곡가순은 Tempo Shift → Foundation Pulse → Demo Melody입니다. 테스트 박자 음원도 해당 BPM에 맞춰 갱신했습니다.

`FoundationVerification.RunTestsOnly()`는 빌드 없이 전체 테스트를 실행합니다. 테스트 프로세스 환경 변수 `RHYTHM_DOJO_SKIP_CAPTURE=1`을 설정하면 테스트의 스크린샷 저장도 생략합니다.

## 가로 난이도 선택 UI

Easy, Standard, Hard를 가로로 펼친 카드로 표시하며 각 카드의 색과 테두리로 선택 상태를 강조합니다. 기존 `difficultyList` 필드와 Dropdown 값 변경 이벤트를 유지해 외부 코드에서 값을 변경해도 카드 표시와 난이도별 판정·기록·저장 옵션이 함께 갱신됩니다. 좌우 방향키로 난이도를 즉시 변경하며 상하 방향키로 곡을 선택합니다. 속도 또는 타이밍 슬라이더에 포커스가 있으면 좌우 방향키는 해당 값을 조절합니다. 뒤로가기 팝업이나 곡 로딩 중에는 카드도 잠깁니다. 기존 변수명과 파일명은 변경하지 않았습니다.
