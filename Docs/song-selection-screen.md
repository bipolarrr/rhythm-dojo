# 곡 선택 화면

`SongSelection`은 자유 연습과 실력 검정에서 같은 목인 화면을 사용한다. 모드 제목과 기록 조회는 `Gauge` / `Challenge` 플레이 규칙으로 결정한다. `Bootstrap`과 `SongSelection`을 새 세션에서 직접 실행하면 자유 연습으로 시작하며, 기존 세션의 곡·난이도·옵션은 유지한다.

- 좌우 방향키 또는 목인 옆 버튼으로 곡을 이동한다. 길게 누르면 연타하며, Enter로 시작을 요청하면 마지막 타격과 선택 갱신 후 해당 곡을 불러온다. 상하 방향키와 난이도 버튼은 등록된 채보를 선택한다.
- 제목·작곡가·BPM·길이·커버·채보·기록·현재 곡 번호를 목인 화면에서 확인한다. 빈 목록, 없는 난이도, 재생 불가 원인은 상태 문구로 표시하며 시작을 차단한다. 일시적인 로딩 실패는 재시도할 수 있다.
- ‘곡 목록 · 정렬 / 속도’는 목인 위에 보조 패널을 연다. 전체/즐겨찾기, 제목/작곡가/BPM 정렬, 고정 속도/BPM 연동, 배속, 입력 타이밍 보정, 일반/하드 옵션을 제공한다. 곡 행을 선택해도 패널은 유지한다. 닫으면 목록 버튼으로 초점을 돌려준다.
- 패널은 타격이 끝난 뒤 열 수 있다. 패널이 열린 동안 목인 입력은 차단한다. Esc/게임패드 뒤로 가기는 드롭다운 또는 모드 팝업, 목록 패널 순으로 닫는다. 기본 화면에서는 목인 퇴장 연출 후 `ModeSelection`으로 돌아간다.
- 미리듣기는 최대 12초다. 곡·난이도 변경, 플레이 진입, 화면 해제 시 중단한다. 취소 후 늦게 도착하는 음원도 해제하며 현재 선택을 덮어쓰지 않는다.
- 설정은 기존 설정 팝업을 사용한다. 돌아오면 최신 옵션과 규칙을 표시한다. Gameplay/Results에서 돌아와도 선택과 규칙은 유지하고 목록 패널은 닫힌 상태로 시작한다. 편집기 테스트 플레이의 반환 경로는 기존 navigation이 담당한다.

속도는 1.0~10.0x를 0.1x 단위로, 입력 타이밍은 -200~+200ms로 조절한다. 양수 타이밍은 입력 시각에서 보정값을 빼므로 늦게 전달되는 입력에 사용한다. 음원·채보 오프셋은 별개다. 기존 옵션·즐겨찾기·기록 저장 형식은 유지하며, 정렬과 즐겨찾기 필터는 실행 중에만 유지한다. 새 저장 키는 없다.

`SongSelectionService`가 선택 곡·난이도·스크롤·배속을 소유하고, `SongSelectionList`가 정렬·필터·표시 순서를 소유한다. 정렬 후 선택은 곡 ID로 보존한다. 필터에서 제외되면 첫 곡을, 결과가 비면 선택 없음을 적용한다. `SongSelectionPresentation`은 서비스 데이터에서 표시 정보를 만든다. 화면은 `SongSelectionState`로 목록·팝업·시작 대기·로딩·퇴장을 관리하며, 컨트롤 값이나 곡 행에서 선택 상태를 읽지 않는다.

`SongSelectionLayoutBuilder`가 목인과 보조 패널을 직접 작성하고 `PracticeSelectionLayoutBuilder`가 목인 표시·연출 구성을 작성한다. **Game Tools > Scenes > Build Song Selection** 또는 **Build All Scenes**로 재생성한다. 고정 UI·효과 풀·오디오 소스는 씬에 저장하며, 곡 행만 작성된 템플릿에서 데이터 수에 맞춰 생성·재사용·해제한다. 필수 참조가 없으면 명시적으로 실패한다.

관련 검증은 `SelectionPreferencesTests`, `SongSelectionFlowTests`, `SelectionBrowserTests`, `PracticeSelectionTests`, `MainMenuFlowTests`, `ScenePreparationFlowTests`와 Smoke에서 수행한다. 공통 fixture는 제품 기본 목인 화면을 사용하고 목록 검사는 실제 버튼으로 패널을 연다. 전체 실행과 복원 절차는 [검증 가이드](verification.md)를 따른다.
