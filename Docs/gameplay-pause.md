# Gameplay pause menu

During a playing session, Escape or switching to another window opens the pause menu and freezes the current song. Choose 이어하기 or press Escape in the pause menu to start a three-second countdown on the wooden seal. Escape during the countdown returns to the pause menu. The same menu offers 설정, 처음부터 다시 and 곡 선택. If audio recovery fails, 이어하기 retries recovery and 곡 선택 exits the run.

The song clock, judgments and note presentation remain frozen while the menu, settings or countdown is open. Restart clears the current session and pending resume. Exit uses GameplayCompositionRoot's deferred shutdown. Closing settings returns to the pause menu and preserves editor-playtest return information. Audio configuration changes during pause restore the saved audio sample position on resume.

GameplayHudLayoutBuilder owns the saved menu layout and references; GameplayPauseMenu controls the dialog and countdown. RhythmSessionCoordinator gates advancement, judgments and keyboard restarts while paused. IResumableSongClock extends the existing pause contract without changing existing callers. Released hold keys are reconciled once at the frozen logical time when resuming. `GameplayTiming` converts both Tick and input to song time minus the input offset; the clock input conversion already includes that offset. Display time remains the uncalibrated song time. Rule version 4 uses this same logical timeline for head, maintenance, automatic tail and release judgments.

Results uses the same default cover and legacy-cover replacement rule as Song Selection. A real registered cover takes precedence. Both screens fill and centrally crop the artwork inside a masked frame. Selection headings and song titles use warm ink and a subtle pixel highlight with the shared Maru Buri Title role.
