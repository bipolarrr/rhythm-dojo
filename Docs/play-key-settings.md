# 플레이 키 설정

설정창 왼쪽 **게임플레이** 아래 **키 셋팅** 탭을 연다. 타이틀에서는 카탈로그 기본 모드, 곡 선택에서는 선택한 채보의 모드, 일시정지에서는 현재 플레이 중인 모드를 편집한다. 기본 키와 표시 이름은 해당 모드 정의를 사용한다. 기본 4레인 모드의 키는 **D / F / J / K**다.

1. 변경할 레인의 나무 버튼을 누른다.
2. 사용할 키보드 키를 누른다. 변경 즉시 해당 모드에 자동 저장된다.
3. **기본값으로 복원**을 누르면 해당 모드의 변경분만 제거한다.

레인이 많으면 목록을 스크롤한다. 게임패드 등 비키보드 바인딩은 그대로 표시하며 키보드 변경 버튼을 비활성화한다. 모드 정보를 제공하지 않는 곡은 키 편집을 사용할 수 없다.

다른 레인과 같은 키, 해당 모드의 시작·복귀 키는 지정할 수 없다. 입력 대기 중 Esc는 변경을 취소한다. 기본 모드에서는 Space가 시작/재시작 전용이며, 다른 시작 키를 쓰는 모드에서는 Space를 레인에 지정할 수 있다.

플레이 HUD와 실제 입력, 결과 화면 레인 이름은 같은 모드 설정을 사용한다. 일시정지 메뉴에서 변경하면 HUD가 바로 갱신되고 재개 후 바뀐 키로 플레이한다. 원본 모드 에셋은 수정하지 않는다. 같은 레인 수라도 서로 다른 ModeId의 변경분은 공유하지 않는다.

`PlayKeyBindings`는 `RhythmDojo.PlayKeys.v2` PlayerPrefs에 원래 ModeId별 변경분을 저장한다. ModeId는 문서 규약의 모드 에셋 식별자이며 런타임 복제 객체 이름을 사용하지 않는다. 기존 v1 설정은 `FourLaneMode`에 한 번만 이전하고 원본 v1 값은 남긴다. 새 저장소가 우선하며, 기본값 복원 후 v1을 다시 가져오지 않는다.

곡 공급자는 `SongEntry` 또는 선택 슬롯의 `ChartEntry`에 모드와 ModeId를 제공한다. `PlayableSong`은 문서의 ModeId를 보존해 입력·HUD·결과에 전달한다. 기존 모드 없는 API는 호환용 기본 4레인 경로로 유지한다. `SettingsLayoutBuilder.BuildKeySettings`는 기본 정의와 행 템플릿만 생성하며 개발자 PC의 저장값을 씬에 굽지 않는다. 설정 씬과 공용 `SettingsPopup.prefab`은 같은 View 구조를 사용한다.

관련 검증은 `PlayKeyBindingsTests`와 `KeySettingsFlowTests`다. 테스트는 v1/v2 사용자 설정을 격리하고 종료 시 복원하며, v2는 빈 값과 키 부재도 구분해 보존한다.
