# 채보 에디터

요구사항: [노션 에디터](https://app.notion.com/p/3dbb08ac2cbc80d6a2e1c024830f6338). 확장 에디터의 화면과 기능을 `ChartEditor.unity`의 기본 에디터로 통합했다. 타이틀 오른쪽 아래 **채보 에디터** 버튼 하나로 연다. 별도의 확장 에디터 버튼과 `ChartWorkspace.unity` 씬은 제거했다.

- 기존 4레인 입력, 드래그 롱노트, RGB 파형, 그리드·템포 편집, 난이도 슬롯, Undo/Redo를 공유한다.
- 파일·설정·편집·도구·재생 메뉴는 Unity 메뉴 바처럼 밝은 회색 바 위에 작은 텍스트로 표시하며, 마우스를 올리면 연한 파란색으로 강조한다. 상단 바 높이는 26, 제목 클릭 영역은 48 × 24, 펼침 항목 높이는 24이며 글자 크기는 14이다. 펼침 메뉴 너비는 가장 긴 항목에 맞추고 높이는 콘텐츠에 맞춰 빈 공간을 없앤다. 긴 메뉴만 최대 높이 620에서 스크롤한다. 펼침 메뉴는 회색 배경과 왼쪽 정렬 항목을 사용한다. 처음에는 클릭해야 열리고, 메뉴가 열린 상태에서는 다른 메뉴 제목에 마우스를 올리면 전환된다. 마우스가 메뉴 밖으로 나가도 유지하며 같은 제목 재클릭, 바깥 클릭, Esc, 메뉴 명령 선택으로 닫힌다. 바깥 클릭은 아래 채보에 전달하지 않는다. 최근 파일 드롭다운도 클릭으로 연다. 긴 메뉴는 휠로 스크롤한다.
- **파일**: 새로 만들기, 최근 저장 순 파일 열기, 저장, 다른 이름으로 저장, PUPA 가져오기, 종료. 새로 만들기는 미저장 변경이 있으면 “현재 파일을 저장하시겠습니까?”를 표시한다. **NO**는 저장하지 않고, **YES**는 현재 작업을 저장한 뒤 새 채보를 만든다. 저장에 실패하면 현재 작업과 확인 창을 유지한다. 저장된 상태에서는 바로 새 채보를 만든다. 열기는 현재 작업을 자동 저장한다. 다른 이름으로 저장은 버튼을 누르면 이름 입력 창을 열며, 현재 이름을 수정한 뒤 저장하거나 취소할 수 있다. 파일 메뉴에는 이름 입력칸을 두지 않는다. 빈 이름은 저장하지 않고, Esc로도 취소할 수 있다. 저장 시 곡과 채보 UUID를 새로 만들고 음원·자켓·노트 사운드를 복사한다. 복사 저장에 실패하면 현재 작업과 입력한 이름을 유지한다. 종료 시 미저장 변경이 있으면 저장 후 종료 / 저장하지 않고 종료 / 취소를 제공한다.
- **설정**: 곡 제목, 작곡가, 자켓 이미지(PNG/JPG), 난이도, 음원(WAV/OGG/MP3), 볼륨(%), BPM, 오디오 시작 타이밍(ms). 메타 정보 머리말과 노트 사운드 입력칸은 제거했다. Easy/Standard/Hard 버튼은 설정 메뉴 안에서 선택한다. 채보 에디터의 첫 진입과 새로 만들기는 Easy로 시작하며, 현재 선택한 난이도 버튼을 어둡게 표시한다. 선택 표시는 마우스를 옮기거나 메뉴를 다시 열어도 유지된다. 제목·작곡가는 입력을 마치고 포커스를 옮기면 바로 반영한다. 이미지·음원 전체 경로는 입력 후 Enter 또는 포커스 이동 시 자동으로 가져오며, 별도 적용/가져오기 버튼도 사용할 수 있다. 자동 가져오기 중에도 설정 메뉴를 유지하고 실패 이유는 상태에 표시한다. 시작 타이밍의 부호는 기존 오디오 오프셋 계약을 따른다.
- **BPM**: 설정과 파형의 BPM 입력칸이 서로 연동된다. BPM 자동 측정 버튼을 제공하며 별도의 단축키는 두지 않는다.
- **편집**: 선택 노트 복사, 현재 파형 커서에 붙여넣기, 삭제, 전체·종류별 선택, 선택 해제, 좌우 반전, 랜덤 레인 순열. 붙여넣기는 노트 간 시간·롱노트 길이를 유지하고 하나의 Undo 단위로 처리한다. 랜덤 배치는 선택 집합에 같은 레인 순열을 적용한다.
- **도구**: 선택, 그리기, 지우개, 잡기를 제공한다. 왼쪽 칸의 도구 제목 글자는 숨기고 화살표·연필·지우개·손 모양 아이콘을 44×44 정사각형 버튼 중앙에 표시하며, 한글 이름 없이 클릭으로 선택한다. 단축키는 오른쪽 아래에 유지한다. 아이콘 아래 퀀타이즈 버튼은 44×44 정사각형에 한글 없이 분수만 가로·세로 중앙에 표시한다. 값은 1/4로 시작하고 클릭할 때마다 1/8, 1/12, 1/16, 1/24, 1/32, 1/48, 1/64, 1/96, 1/192를 거쳐 다시 1/4로 순환한다. 도구 메뉴·파형 드롭다운과 버튼 표시·노트 스냅 간격을 함께 갱신하며 새로 만들기도 1/4로 초기화한다. 현재 도구는 짙은 회색으로 구분하고 상단 도구 메뉴와 선택 상태를 공유한다. 선택된 노트가 있을 때 지우개 버튼이나 메뉴를 누르면 선택 전체를 한 번에 삭제한다. 지우개 모드에서 선택된 노트를 클릭해도 선택 전체를 삭제하며, 선택하지 않은 노트는 클릭한 노트만 삭제한다. 묶음 삭제는 한 번의 Undo/Redo 단위로 처리한다. 잡기는 노트를 누른 채 드래그해 레인과 시점을 옮긴다. 선택된 노트를 잡으면 선택된 노트 전체를 함께 옮기며, 선택하지 않은 노트를 잡으면 그 노트만 옮긴다. 묶음의 레인 간격·시간 간격·롱노트 길이·선택 상태를 유지하고 전체 미리보기를 표시한다. 묶음 전체가 레인 범위와 0초 안에 남도록 이동량을 제한하며, 선택 밖의 노트와 겹치면 전체 이동을 취소한다. 여러 노트 이동도 한 번의 Undo 단위다. 시작 시점은 퀀타이즈에 맞추고 롱노트 길이와 노트 ID를 유지한다. 드래그 중 미리보기를 표시하고 놓을 때 한 번의 Undo 단위로 반영한다. 다른 노트와 겹치는 이동은 거부하며, 그리드 밖에 놓거나 Esc를 누르면 취소한다. 빈 곳을 잡아도 새 노트를 만들지 않는다. 선택은 클릭 토글 및 드래그 범위 선택(선택 노트는 금색)을 사용하며, 그리기는 기존 드래그 롱노트 입력을 유지한다. 별도의 탭 노트·롱노트 버튼은 표시하지 않는다. 퀀타이즈는 1/4, 1/8, 1/12, 1/16, 1/24, 1/32, 1/48, 1/64, 1/96, 1/192를 지원한다.
- **재생**: 재생/일시정지(Space), 처음으로, 실제 Gameplay 테스트. 입력칸 편집 중이나 확인 창에서는 Space 단축키를 처리하지 않는다. 루프·저속 재생 컨트롤과 볼륨 안내·재생 상태 문구는 재생 메뉴에 표시하지 않는다. 현재 위치 테스트는 커서 이전에 시작하는 노트를 제외한 임시 재생 문서를 사용한다. 원본 채보는 바꾸지 않는다. 오토 테스트는 노트 시각에 자동 입력한다. 테스트 기록은 기존 에디터 테스트와 동일하게 정식 곡 기록에 저장하지 않는다. 게임에서 Esc로 돌아오면 편집 세션과 Undo 이력이 유지된다.

채보는 기존 v3 JSON 계약을 유지한다. 자켓·노트 사운드는 기존 해시 기반 파일 복사 저장소를 사용하고, 볼륨과 리소스 상대 경로는 곡 폴더의 `workspace.json`에 별도로 저장한다. 이 추가 설정은 기존 에디터와 플레이어의 채보 파싱에 영향을 주지 않는다. 제목·작곡가는 입력 완료 시 편집 세션에 반영된다. BPM은 설정과 파형 입력칸이 서로 연동되며 입력 완료 시 반영한다. Undo/Redo와 파형의 BPM 변경도 양쪽에 반영한다. 볼륨은 막대를 좌우로 드래그해 0–100%로 조절하며 숫자·배경 채움과 미리듣기 음량을 즉시 갱신한다. 볼륨 채움은 선택된 난이도 버튼과 같은 회색을 사용한다. 시작 타이밍은 **설정 적용** 후 저장한다. 기존 문서의 노트 사운드 리소스는 유지하지만 설정 메뉴에서 새 노트 사운드를 가져오지는 않는다.

재생성: **Game Tools > Scenes > Build Chart Editor**. 기존 **Build Extended Chart Editor** 명령도 같은 기본 에디터를 생성하는 호환 진입점이다. **Build All Scenes**는 공통 기반을 만든 뒤 현재 인터페이스를 한 번 적용해 `ChartEditor.unity`만 생성한다. 씬을 직접 수정하는 대신 빌더에 변경을 반영한다.

검증 범위: `WorkspaceEditingTests`, `WorkspaceEditorTests`, 기존 `ChartEditorMenuTests`·`AudioTimelineTests`·타이틀 이동과 Smoke. 공유 재생 시계·에디터 계약 변경에 대해서는 전체 무빌드 검증을 수행한다.

## 단축키

입력칸에 글자를 쓰는 중에는 편집기 단축키를 실행하지 않는다. Ctrl/Shift/Alt 조합은 정확히 일치할 때만 처리한다. 상단 메뉴와 왼쪽 도구 아이콘의 단축키는 기능 이름과 분리한 오른쪽 정렬 열로 표시한다. 난이도의 Alt+1/2/3 동작은 유지하되 표시하지 않는다.

| 메뉴 | 기능 | 단축키 |
| --- | --- | --- |
| 파일 | 새로 만들기 / 파일 열기 | Ctrl+N / 없음 |
| 파일 | 저장 / 다른 이름으로 저장 | Ctrl+S / Ctrl+Shift+S |
| 파일 | PUPA 가져오기 / 타이틀로 | Ctrl+Shift+I / Esc |
| 설정 | 자켓 적용 / 음원 가져오기 | 없음 |
| 설정 | Easy / Standard / Hard | Alt+1 / Alt+2 / Alt+3 (표시 숨김) |
| 설정 | 설정 적용 | Ctrl+Enter |
| 편집 | 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y |
| 편집 | 복사 / 붙여넣기 / 삭제 | Ctrl+C / Ctrl+V / Delete |
| 편집 | 전체 / 탭 / 롱노트 선택 | Ctrl+A / Ctrl+1 / Ctrl+2 |
| 편집 | 선택 해제 / 좌우 반전 / 랜덤 배치 | Ctrl+Shift+A / Ctrl+M / Ctrl+Shift+R |
| 도구 | 선택 / 그리기 / 지우개 / 잡기 | V / P / E / G |
| 재생 | 재생·일시정지 / 처음으로 | Space / 0 |
| 재생 | 테스트 / 현재 위치 테스트 | F5 / Shift+F5 |
| 재생 | 오토 테스트 / 현재 위치 오토 | Ctrl+F5 / Ctrl+Shift+F5 |

Esc는 이동 미리보기 취소, 팝업 취소, 열린 메뉴·드롭다운 닫기를 먼저 처리한다. 입력 중이면 입력을 종료하고, 열린 창이 없으면 기존 저장 확인 절차를 거쳐 타이틀로 나간다. 새로 만들기 확인 창에서도 Esc로 기존 작업을 유지하며 취소할 수 있다. 확인 창의 Enter는 기본 확인 동작을 실행하며, 버튼에 키보드 포커스가 있으면 그 버튼의 기존 Enter 동작을 따른다.

## 작업 내역

기존 에디터를 동일하게 복제해 별도의 확장 에디터에서 작업한 다음, 완성된 화면과 기능을 기본 채보 에디터로 다시 통합했다. 별도의 확장 에디터 진입 버튼과 중복 씬을 정리하고 기본 에디터 하나로 사용하도록 변경했다.

에디터 툴과 도구를 추가·개선했다. 선택·그리기·지우개·잡기 아이콘, 선택 묶음 이동·삭제, 클릭 순환 퀀타이즈, 파일 저장 확인·다른 이름으로 저장, BPM 입력 연동과 볼륨 조절을 반영했다. 메뉴별 단축키를 설정하고 불필요한 조합을 제거했으며, 표시를 우측 정렬해 정리했다.
