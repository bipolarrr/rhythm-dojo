## 작성된 씬과 모션

`MainMenuLayoutBuilder` → `AlphaDojoLayoutBuilder` → `DojoRenewalLayoutBuilder`에서 고정 구성을 작성한다. **Game Tools > Scenes > Build Title**로 재생성하며 Build All에도 포함된다. 이번 작업에서는 Title만 재생성한다.

입구 프레임과 한지문 두 장, 문 뒤 공간, 클릭 영역, 로고, 입장 안내를 별도로 작성한다. 문은 `Door Aperture`의 RectMask2D 안에서 기둥 뒤로 이동한다. 두드린 직후 작은 반동을 거쳐 무게감 있게 열리고, 문간을 지나 수련 공간으로 접근한다. 입구의 공기감은 낮은 불투명도의 작은 먼지 3개만 사용한다. 정적인 처마·소품은 배경에 남기고 꽃잎 루프는 사용하지 않는다.

비급 전수는 측면 툇마루·교재장·낮은 교탁이 있는 밝은 수업방이다. 기존 설명판을 왼쪽 뒤에 두고, 플레이어와 여성 선배 사형이 앞쪽의 같은 바닥에서 목인을 사이에 두고 마주 본다. 사형은 도장의 기초 수련 담당이며, 네 박자 표식·손짓·칭찬과 자세 교정 반응이 실제 연습 판정과 연결된다. 자유 연습의 넓은 전망 도장, 실력 검정의 산정 배경과 구도가 다르다.

화면비가 달라도 `DojoCompositionFit`이 입구/수련 무대 전체를 같은 비율로 맞춘다. 배경만 확대하고 인물은 그대로 두어 발이 바닥에서 뜨던 문제와 울트라와이드의 현판/안내 잘림을 방지한다. 남는 영역은 기존 도장 배경을 어둡게 재사용한다. 화면 상하의 조작 UI는 별도 안전 영역을 사용한다.

`DojoModeView.characterMarks`는 각 장소의 수련생 위치다. 같은 캐릭터가 기존 달리기 두 프레임으로 이동해 새 위치에 도착한다. 대기 호흡, 타격과 목인 반응, 사부의 박자 손짓, 기존 선인 옷자락, 수업방 먼지/산정 바람을 사용한다. `DojoAmbientMotion`은 씬에 저장한 대상만 움직이고 비활성화 시 원래 자세로 복원한다. 런타임 고정 오브젝트·텍스처 생성은 없다.

## 생성과 확인

내장 `image_gen` 사용. 최종 파일은 `Assets/Game/Art/DojoRenewal/`에 저장했다. 프롬프트와 출처는 [dojo-renewal-prompts.json](dojo-renewal-prompts.json)에 기록했다. 참조 제공 이전의 입구 시안은 프로젝트에 넣지 않았다.

## 모드 선택 아케이드 UI 개편

추가 요구사항에 따라 모드 선택의 공통 제목판과 하단 정보판을 제거했다. `AlphaDojoLayoutBuilder`가 `DojoArcadeLayoutBuilder`를 호출해 네 모드의 타이포그래피와 조작 UI를 씬에 작성한다. 입구와 기존 인물·배경 원본은 유지한다. 자유 연습의 두루마리는 오른쪽에 두어 큰 제목의 공간을 확보하고, 사부의 안내 문구는 비급 설명과 겹치지 않도록 오른쪽 교재 영역에 배치한다.

| 모드 | 구도 |
| --- | --- |
| 비급 전수 | 밝은 수업방 상단에 먹색 가로 제목과 주홍색 붓 획. 사부와 수련생 사이의 공간은 비워 둔다. |
| 자유 연습 | 왼쪽에 큰 두 줄 제목, 따뜻한 종이색과 주황색 획. 전망과 수련 동작은 오른쪽으로 열린다. |
| 실력 검정 | 선인 왼쪽 하늘에 넓은 먹색 제목. 다른 모드보다 작은 이동 거리와 절제된 오버슈트를 사용한다. |
| 새로운 수련 | 같은 글꼴·색상 체계의 두 줄 제목과 준비 중 표시. 기존 진입 제한과 순환 이동을 유지한다. |

제목·설명·보조 문구는 모두 실제 Unity `Text`다. 제목은 기존 [Dokdo / SIL OFL 1.1](../Assets/Game/Fonts/Dokdo-OFL.txt), 본문은 기존 [Maru Buri / SIL OFL 1.1](../Assets/Game/Resources/UI/MaruBuri-OFL.txt)를 사용한다. 새 글꼴이나 이미지에 구운 글자는 추가하지 않았다. `DojoInkGraphic`은 씬에 작성된 벡터 붓 획과 가장자리가 부드러운 국소 명암을 그리며, 프레임이나 불투명 사각 패널은 만들지 않는다.

`Mode Stages / Mode Heading / Mode Typography 1–4` 아래의 RectTransform, Text, 색상을 Inspector에서 확인할 수 있다. 각 `DojoModeTypography`의 `enterSeconds`, `copyDelay`, `copySeconds`, `entryDistance`, `overshoot`로 연출을 조정한다. `DojoModeView.titleExit`와 `titleArrival`은 공간 이동 진행률 기준이다. 기본 0.82초 전환 안에서 이전 제목이 0.13초 동안 달리는 방향으로 퇴장하고, 약 0.51초부터 새 제목이 진입한다. 설명은 0.08초 뒤에 나타나며 도착할 때 정착한다. 도착 시 선택 획의 짧은 펄스를 사용하며, 타격음은 실제 목인 접촉 때만 재생한다. 수업 중 박자 안내음은 사부의 지시 손짓과 연결한다. 추가 입력 대기 시간은 없다.

네 구도와 공통 조작 UI는 `DojoCompositionFit` 안에 배치하여 4:3과 울트라와이드에서도 인물·배경과 같은 비율을 유지한다. 선택 상태는 네 개의 박자 표식과 번호로 표시하고, 좌우 화살표와 실제 버튼 클릭 영역은 유지한다. 런타임에는 작성된 오브젝트의 위치·배율·알파만 바꾸며, 이동 취소와 재입장 때 같은 인스턴스를 복원한다. Inspector에서 실험한 값의 영구 반영은 빌더를 수정한 뒤 **Build Title**로 재생성한다.

이번 개편의 변경 전·후 캡처와 검증 근거는 [아케이드 UI 검증](../Logs/arcade-ui-verification.md)에 기록한다.

## 장면 맥락에 맞춘 모션

플레이어와 사형·선인 전체의 상하 왕복, 전신 스케일 호흡, 목제 설명판 전체의 흔들림을 제거했다. `DojoFigureGraphic`은 스프라이트의 UV를 유지한 연속 메시를 사용한다. 하단의 발 정점은 고정하고 가슴·손·머리·천 부분의 위치만 작게 변형한다. 플레이어·선인 원본은 유지하고, 여성 사형만 같은 화풍의 새 스프라이트 세트를 사용한다. 런타임 오브젝트, 텍스처, 재질 복제는 없다. 모든 Image와 버튼은 빌더가 씬에 저장하고 참조 누락을 명시적으로 검사한다.

- 비급 전수: 작은 호흡과 집중한 상체, 사부의 지시봉·소매 손짓. 수업의 박자 신호마다 짧게 지시하고 그 외에는 안정적으로 선다.
- 자유 연습: 조금 더 여유 있는 호흡과 체중 이동, 드문 시선 변화. 목인 클릭 또는 Space로 준비·뻗기·접촉·복귀를 수행한다. Enter의 수련 시작 동작은 유지한다.
- 실력 검정: 절제된 준비 자세와 선인의 짧은 수락 동작. 사부·선인의 루트는 움직이지 않으며 선인의 수염·옷자락과 깃발은 같은 느린 우향 바람을 따른다.
- 도구: 도착 시 한 번의 시범 또는 실제 입력에만 목인이 반응한다. 입력 후 약 0.22초에 접촉음과 접촉 횟수를 기록하고, 목인 반동은 약 0.025초 뒤 시작한다. 수련생은 약 0.54초에 자세를 회복하며 목인은 접촉 후 0.85초 안에 완전히 멈춘다. 준비 중 연타는 새 타격을 겹치지 않고, 화면 이동·닫기는 미완료 접촉을 취소한다.
- 환경: 수업방의 종이 부분만 약하게 움직이고 목재 지지대는 고정한다. 입구·수업방·산정에 각각 작은 먼지 3개만 작성한다. 깃발은 고정된 걸이점에서 끝으로 파동이 흐르며 중력에 따라 아래로 처진다. 배경 전체를 흔드는 연출은 없다.

`MainMenuFlowTests`는 실제 버튼 입력과 접촉 순서, 반동 정착·취소, 발의 렌더링 정점 고정, 상체 움직임, 새 입력 없는 반복 타격 금지 및 기존 메뉴 재개·모드 이동을 검증한다. 구현과 씬을 함께 수정하고 **Build Title**로 다시 작성한다. 검증 기록과 모션 캡처는 `Logs/contextual-motion/`에 저장한다.

검증: 관련 메뉴 PlayMode 25개, EditMode 5개, 공통 이동 Smoke 4개가 모두 통과했다(skip/inconclusive 없음). Smoke의 타이틀 이동 1개는 메뉴 검사와 중복된다. Space 입력의 실제 Input System 경로와 native 입력 복원도 별도 확인했다. 전체 프로젝트 검사나 플레이어 빌드는 실행하지 않았다. [상세 결과](../Logs/contextual-motion/verification.json)와 [무음 모션 영상](../Logs/contextual-motion/motion-review.mp4)을 참고한다. 영상은 실행 중인 씬의 오프스크린 렌더링이며 프레임 간 실제 경과 시간을 반영했다.

## 여성 사형과 랜덤 대기 동작 확장

위의 최초 모션 작업 이후, 비급 전수의 노년 지도자를 여성 선배 사형으로 교체했다. `AlphaDojo/SeniorStudent.png`는 기존 `Actors.png`를 화풍 참조로 내장 `image_gen`에서 생성한 투명 3×2 시트다. 검은 포니테일, 짧은 청록 조끼, 붉은 허리띠로 플레이어와 구분하며 같은 도장의 실전형 선배로 표현한다. 원본 플레이어·선인·목인 자산과 GUID는 보존한다. [생성 프롬프트와 프레임 순서](dojo-senior-prompts.json).

| 인물 | 기본 대기 외 동작 | 랜덤 대기 |
| --- | --- | --- |
| 플레이어 / 비급 전수 | 자세 고치기, 손 풀기, 고개 끄덕이기, 짧은 시범 | 2.8–5.8초 |
| 플레이어 / 자유 연습 | 위 네 동작 + 주변 살피기 | 2.8–5.8초 |
| 플레이어 / 실력 검정 | 자세 고치기, 손 풀기, 선인 올려다보기, 낮게 집중하기 | 2.8–5.8초 |
| 여성 사형 | 설명, 표적 가리키기, 격려, 팔짱 관찰, 짧은 시범 | 4.2–7.2초 |
| 선인 | 시선 이동, 소매 정리, 옷자락의 큰 바람 반응 | 7–12초 |

`DojoModeView`의 `traineeIdle`, `teacherIdle`, `sageIdle`에 목록, 가중치, 길이, 모드 마스크, 스프라이트, 최소/최대 대기를 작성한다. `enabled`로 인물별 재생을 끈다. `DojoIdleVariation`은 직전 동작을 제외한 가중치 추첨을 하며, 동작 종료 뒤 새 대기를 뽑는다. `idleSeparation`은 서로 다른 동작 사이의 여백이다. 시작 허가는 씬 단위로 조정하여 두 인물의 독립 동작이 겹치지 않는다. 선배의 동작 뒤에는 플레이어가 끄덕이거나 자세를 고쳐 반응한다. 반응도 직전 동작 중복을 피한다.

입장·이동·퇴장·팝업, 박자 수업 전체, 타격·반동·평가 중에는 랜덤 동작을 취소하고 기본 자세로 돌린다. 수업에서는 박자 손짓이 우선하며 정답은 격려, 실수는 관찰 자세와 교정 문구로 응답한다. 기본 호흡·종이 바람은 계속 작게 유지한다. 목인은 실제 접촉 횟수에 따라 가벼운 반동과 더 깊은 반동을 번갈아 사용하고 0.85초 안에 정착한다. 랜덤 시범은 접촉음이나 타격을 만들지 않는다.

고정 배치와 여섯 사형 스프라이트는 `AlphaDojoLayoutBuilder`가 작성하며 **Build Title**과 **Build All Scenes**로 재생성한다. 시트의 포즈별 여백 차이는 에디터에서 뒤쪽 신발의 위치를 기준으로 Sprite rect에 보정한다. 발을 고정하는 메시 동작과 Sprite Swap을 조합하고 플레이어 시범은 기존 타격 프레임을 재사용한다. 런타임 텍스처·재질·오브젝트 생성은 추가하지 않는다. 이번 확장의 검증 결과와 캡처는 `Logs/senior-idle/`에 저장한다.

관련 EditMode·메뉴 PlayMode·공통 이동 Smoke를 통과했고, 최종 포즈 변경 후 해당 회귀 검사와 씬 재생성 후 메뉴 구성을 다시 확인했다. 기본 설정의 약 80초 관측에서 동작 중첩·직전 동작 반복·대기 중 가짜 접촉은 없었다. 16:9, 4:3, 울트라와이드 화면을 확인했다. 전체 프로젝트 검사와 플레이어 빌드는 실행하지 않았다. [검증 기록](../Logs/senior-idle/verification.json), [최종 장면](../Logs/senior-idle/lesson.png), [모션 영상](../Logs/senior-idle/motion-review.mp4). 영상은 실제 경과 시간을 반영한 오프스크린 캡처이며, 이동 중에는 직전 프레임이 유지된다. 플레이어의 짧은 시범은 별도 관측에서도 접촉을 만들지 않고 기본 자세로 복귀했다.
